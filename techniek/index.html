    Technische specificaties

    Alle uitspraken op deze site zijn gemeten. Waar anderen een persbericht publiceren, publiceren wij de meetresultaten. Testruns, benchmarks en methodiek delen wij per claim op verzoek. Deze pagina is voor wie de cijfers wil zien; de homepage vertelt wat het voor jou doet.

    Snelheid

    Gemeten over 11 scenario's draait NoodleCore-code gemiddeld op 95,9% van de tijd van handgeschreven C — dus 4% sneller. Geen schatting; wie de benchmarkrapporten wil zien, krijgt ze op vraag.

    noodle run versnelt bestaande Python van binnenuit — net zoals Ruff en uv de Python-wereld versnelden, maar dan voor jouw code:

    hot loop in Python     217 ms
zelfde loop via NC      34 ms    (6,4×)
in-process (dylib)      0,9 ms   (243×)

    Geen runtime-meelopers, geen tolk tussen jouw code en de CPU.

    Zelfcompilerend (self-hosting)

    De compiler is geschreven in NoodleCore en compileert zichzelf. Aangetoond met een fixed-point test — het criterium dat GCC hiervoor gebruikt. Sinds mei 2026 draait de compiler op deze manier; alle 228/228 modules komen uit dit proces.

    Database in de taal (NoodleDB)

    SELECT is een taalconstructie, geen externe server. Transacties, graph, vector-search en full-text zitten in dezelfde engine: geen driver, geen connector, geen tweede taal. Elke PostgreSQL-client kan rechtstreeks verbinden; elke MySQL-client sluit aan op het MySQL-protocol. Data uit SQLite, PostgreSQL en MySQL importeer je zomaar mee. Per type vraag tot 1,8× sneller dan SQLite, A/B-getest op identieke machines.

    Geheugen

    • Gebruikerscode schrijft nooit zelf geheugen toe of vrij: de runtime regelt allocatie, groei en opruiming (Array Memory Model met lengte/capaciteit-header).
    • Bewijs: alle 240 stdlib-modules en de voorbeelden draaien zonder één handmatige geheugenverklaring.
    • Type-mismatch op getal-buffers is een harde compileerfout (4 richtingen afgedekt, met bestand:regel:kolom) — een vergissing kan nooit meer stil als 0 teruggelezen worden (NOO-1700, pitfall P25).

    AI-kernels

    NoodleCore zelf bevat geen model en stuurt niets naar buiten. Wil je AI gebruiken, dan praat je code ermee op eigen kernels, op je eigen hardware: geen API-key, geen cloud. Bewezen tot en met een GPU uit 2017: 41,7 tok/s, bit-exact.

    Legacy mét weg terug

    COBOL, RPG, VB6 en Fortran worden NoodleCore, en NoodleCore wordt C: vertalen kan in beide richtingen, je raakt nooit vast aan één leverancier. De NIST COBOL-suite (459/459) is de referentieproef.
