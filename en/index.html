    Easy as Python · fast as C

    Fast as C,
    readable as Python,
    and it compiles itself!

    NoodleCore compiles its own code to native C. Measured across 11 scenarios, the result is on average 4% faster than hand-written C. With a database built in — not a separate product but a language feature: SELECT sits right next to if/for, in the same file, no server, no driver, no installation.

    ⚡ Faster than hand-written C

    Measured across 11 scenarios: 95.9% of C's runtime on average, so 4% faster. No estimates — ask for the benchmark reports and you'll get them.

    🔁 Compiles itself

    Proven with a fixed-point test, the same criterion GCC is held to. Running this way since May 2026.

    🧱 Database included

    SELECT is a language construct, not an external server. Transactions, graph, vector search and full-text live in the same engine — no driver, no connector, no second language. Every PostgreSQL client connects directly; every MySQL client speaks to the MySQL protocol. Data from SQLite, PostgreSQL and MySQL imports right along. Up to 1.8× faster than SQLite per query type, A/B-tested on identical machines.

    🤖 No AI ínside the language — but it talks to AI

    NoodleCore itself contains no model and sends nothing anywhere. When you do want AI, your code talks to it on our own kernels, on your own hardware: no API key, no cloud. Proven down to a 2017 GPU: 41.7 tok/s, bit-exact.

    🚀 Future + legacy in one

    Mature database behavior for today's work (JSON, vectors, full-text) and an import path for what you already have. Your existing data isn't dead weight — it's the starting point.

    🌉 Legacy with a way back — and C and Python as friends

    COBOL, RPG, VB6 and Fortran become NoodleCore, and NoodleCore becomes C: translation works in both directions, so you're never locked in to one vendor. C and Python aren't strangers but neighbors: noodle run accelerates existing Python without a rewrite, and the C translation opens your system to every C tool you already know.

    See it yourself

    Open the Examples: Python and NoodleCore side by side, with the measured gain per kind of work — a prime-number loop, text processing and a database query.

    Built for

    • Python teams hitting a speed wall: your script, at C speed — no migration, no rewrite. Port only the compute-intensive loops, keep the rest
    • Companies with legacy code (COBOL, VB6, RPG): modernize without rewriting — with a way back
    • Anyone who wants speed ánd control without C boilerplate or a steep learning curve

    How it works without a migration

    You don't have to choose between simple and fast. noodle run speeds up your existing Python script from the inside — the way Ruff and uv sped up the Python world, but for your code:

    hot loop in Python     217 ms
same loop via NC        34 ms    (6.4x)
in-process (dylib)      0.9 ms   (243x)

    No runtime tag-alongs, no interpreter standing between your code and the CPU. The full move to NC happens naturally — every kernel you port proves the language.
