    Easy as Python · fast as C

    Snel als C,
    leesbaar als Python,
    én zelfcompilerend!

    NoodleCore compileert zijn eigen code naar native C.
    Gemeten over 11 scenario's is het resultaat gemiddeld 4% sneller dan handgeschreven C. Met een geïntegreerde database, dus geen los product maar een taalfunctie: SELECT staat gewoon naast if/for, in hetzelfde bestand, zonder server, zonder driver en zonder installatie.

    ⚡ Sneller dan handgeschreven C

    Gemeten over 11 scenario's: gemiddeld 95,9% van de C-tijd, dus 4% sneller. Geen schatting; wie de benchmarkrapporten wil zien, krijgt ze op vraag.

    🔁 Compileert zichzelf

    Aangetoond met een fixed-point test, het criterium dat GCC hiervoor gebruikt. Draait zo sinds mei 2026.

    🧱 Database inbegrepen

    SELECT is een taalconstructie, geen externe server. Transacties, graph, vector-search en full-text zitten in dezelfde engine: geen driver, geen connector, geen tweede taal. Elke PostgreSQL-client kan rechtstreeks verbinden; data uit SQLite, PostgreSQL en MySQL importeer je zomaar mee. Per type vraag tot 1,8× sneller dan SQLite, A/B-getest op identieke machines.

    🚀 Toekomst en legacy in één

    Moderne databasefuncties voor het werk van nu: JSON, vectoren en full-text. En een importpad voor wat je al hebt. Je bestaande data is startpunt, geen ballast.

    🌉 Legacy mét weg terug — en C en Python als vrienden

    COBOL, RPG, VB6 en Fortran worden NoodleCore, en NoodleCore wordt C: vertalen kan in beide richtingen, je raakt nooit vast aan één leverancier. C en Python zijn geen vreemden maar buren: noodle run versnelt bestaande Python zonder herschrijven, en de C-vertaling legt je systeem open voor elke C-tooling die je al kent.

    Zelf kijken

    Open de Voorbeelden: Python en NoodleCore naast elkaar, met de gemeten winst per soort werk. Er staat een priemgetal-loop in, tekstverwerking en een databasevraag.

    Voor wie

    • Python-teams met snelheidsproblemen: jouw script, C-snelheid. Geen overstap, geen herschrijven: poort alleen de rekenintensieve lussen, houd de rest.
    • Bedrijven met legacy-code (COBOL, VB6, RPG): moderniseren zonder herschrijven — met terugweg
    • Iedereen die snelheid én controle wil zonder C-boilerplate of leercurve

    Hoe het werkt zonder overstap

    Je hoeft niet te kiezen tussen simpel en snel. noodle run versnelt je bestaande Python-script van binnenuit — net zoals Ruff en uv de Python-wereld versnelden, maar dan voor jouw code:

    hot loop in Python     217 ms
zelfde loop via NC      34 ms    (6,4×)
in-process (dylib)      0,9 ms   (243×)

    Geen runtime-meelopers, geen tolk tussen jouw code en de CPU. De volledige overstap naar NC komt vanzelf — elke kernel die je port, bewijst de taal.
